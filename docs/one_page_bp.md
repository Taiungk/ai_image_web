# AIGC Studio 一页纸商业计划（One-Page BP）V1.1

## 我们做什么
面向创作者与小B商家的 AI 图像/视频生产SaaS，提供多模型生成、稳定交付与商业计费闭环。

## 核心痛点
- 工具分散、切换成本高
- 计费不透明、争议多
- 上游不稳定导致生产中断

## 解决方案
- 统一创作入口（图像+视频）
- 多上游模型网关（主备路由+熔断）
- 会员订阅+钱包充值双轨计费
- 任务中心+资产中心沉淀内容资产

## 商业模式
1. 订阅套餐：Basic / Pro / Business
2. 超额消耗：按次/按秒扣费
3. 加油包：图像次数包、视频秒数包
4. 增量收入：企业版、API开放

## 核心壁垒
- 模型调度与成本优化能力
- 计费幂等与账实一致能力
- 资产沉淀与运营体系能力

## 路线图
- V1（6周）：完整交易与创作闭环
- V1.5（+4周）：活动与增长机制增强
- V2（+8周）：企业版与API生态
