# AIGC Studio 详细PRD（可评审版）V1.1

日期：2026-04-29  
版本范围：V1（6周上线）+ V1.5（2~4周增强）

## 1. 产品目标
- 构建面向创作者与小B商家的 AI 生图/生视频平台。
- 通过“多模型 + 多上游 + 商业闭环”实现稳定交付与可持续营收。
- 在60天内验证付费闭环与毛利模型。

## 2. 用户与场景
### 2.1 目标用户
1. C端创作者：短视频、自媒体、设计爱好者。  
2. 小B商家：电商商家、工作室、MCN内容团队。

### 2.2 核心场景
- 生成电商主图与活动海报。
- 生成短视频素材与封面图。
- 资产长期沉淀、复用、下载与清理。

## 3. V1功能范围
- 登录注册：手机号验证码、微信扫码。
- 创作中心：banana2 / banana pro / image2 / veo。
- 任务中心：排队中/生成中/成功/失败，失败任务可重试一次。
- 资产中心：查看、筛选、下载、删除、恢复（回收站7天）。
- 会员中心：套餐购买、续费、权益展示。
- 钱包中心：微信/支付宝充值、余额与流水。
- 账单中心：预扣/实扣/返还明细。
- 运营后台：模型路由、套餐配置、订单与用户管理、审计日志。

## 4. 商业规则（固定）
- 套餐：Basic ¥39 / Pro ¥99 / Business ¥299（月）。
- 扣费顺序：套餐权益 > 钱包余额 > 引导充值/升级。
- 任务计费：提交预扣，成功实扣，失败返还，超时返还。
- 充值：最低¥10，余额不过期，不可提现。

## 5. 关键指标（上线后60天）
- 注册转付费率 ≥ 6%
- 7日留存 ≥ 25%
- 生成成功率 ≥ 97%
- 支付成功率 ≥ 92%
- 计费争议率 ≤ 0.5%

## 6. 核心流程验收
### 6.1 生成流程
1. 提交任务时完成权限、风控与额度校验。  
2. 成功冻结额度后才允许入队。  
3. 成功任务必须有资产记录与实扣流水。  
4. 失败任务必须有返还流水。

### 6.2 支付流程
1. 创建订单 -> 拉起支付 -> 回调验签。  
2. 幂等更新订单状态。  
3. 充值到账或权益发放成功。

## 7. 非功能需求
- API（不含生成耗时）P95 < 500ms。
- 支付、结算、回调全链路幂等。
- trace_id贯穿任务、计费、支付、资产。
- 风控合规：敏感词审核、限流、防刷、协议与隐私政策。

## 8. V1.5增强
- 优惠券体系（满减/折扣）。
- 邀请返利与新手任务。
- 自动切备通道与渠道健康度可视化。
