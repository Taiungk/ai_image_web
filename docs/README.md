# AIGC Studio 文档导航

本目录用于支持 AIGC Studio 从0到1落地，覆盖产品、研发、运营与对外沟通。

## 1. 快速阅读顺序（推荐）
1. `prd_v1.md`：先明确做什么、给谁做、商业规则与验收指标。
2. `tech_design_v1.md`：确认架构、状态机、幂等与一致性方案。
3. `jira_backlog.md`：按6周里程碑拆分执行。
4. `ops_sop.md`：上线后按SOP执行运营与客服处理。
5. `one_page_bp.md` / `pitch_3min.md` / `investor_qa.md`：用于对外沟通。

## 2. 按角色阅读
### 产品经理
- 必读：`prd_v1.md`
- 关注：功能范围、商业规则、指标与验收。

### 技术负责人
- 必读：`tech_design_v1.md`
- 关注：模块职责、幂等键、一致性补偿、监控阈值。

### 项目经理 / Scrum Master
- 必读：`jira_backlog.md`
- 关注：Sprint目标、DoD、上线阻塞项。

### 运营与客服
- 必读：`ops_sop.md`
- 关注：活动、定价复盘、SLA与退款判责。

### 创始人 / BD / 融资沟通
- 必读：`one_page_bp.md`、`pitch_3min.md`、`investor_qa.md`
- 关注：差异化、商业模式、风险预案与口径一致性。

## 3. 当前版本与使用方式
- 当前版本：V1.2 文档包
- 使用建议：
  - 每次需求变更先更新 `prd_v1.md`。
  - 每次技术方案调整同步更新 `tech_design_v1.md` 与 `jira_backlog.md`。
  - 每月运营复盘后更新 `ops_sop.md` 中阈值与策略。

## 4. 上线前最小检查
- [ ] PRD范围冻结（无临时加需求）
- [ ] 支付回调幂等验证通过
- [ ] 扣费账实一致验证通过
- [ ] 失败返还机制验证通过
- [ ] 监控告警可用
- [ ] 协议与隐私政策上线
