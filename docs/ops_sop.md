# AIGC Studio 运营SOP（实战版）V1.1

## 1. 运营目标分期
- 冷启动（0-2个月）：首付费与口碑验证。
- 增长期（2-6个月）：续费率与ARPU提升。
- 稳定期（6个月+）：毛利优化与企业化扩张。

## 2. 定价与毛利机制
- 套餐毛利率目标：>=50%。
- 每月第1个工作日执行成本复盘：按模型与渠道统计真实成本。
- 当套餐毛利<45%时，优先调整权益，再调整价格。

## 3. 活动SOP
### 新客活动
- 注册送基础次数（有效期3天）。
- 首充赠送（如充100送20）。
- 首月订阅折扣券（限一次）。

### 大促活动
- 年包折扣、升档优惠、视频加油包。

### 活动复盘
- 指标：GMV、ROI、新增付费、退款率、毛利率。

## 4. 客服工单处理
- A类（支付到账异常）：30分钟响应，4小时处理。
- B类（扣费争议）：2小时响应，24小时处理。
- C类（质量争议）：24小时响应，可补偿次数。
- D类（封禁申诉）：48小时复核。

## 5. 退款判责
- 系统责任：必退（重复扣费、失败未返还）。
- 用户主观不满意：不退，可补偿体验次数。
- 规则歧义：部分退款或发券补偿。

## 6. 日常巡检
每日 10:00 / 16:00 检查：
- 模型成功率（分渠道）
- 队列积压
- 支付成功率
- 客诉数量
- 套餐毛利看板
